# Runbooks 概述

本目录用于沉淀研发、发布、运维阶段的操作手册，确保关键流程可复现、可交接。

## 文件概述
- [local-dev](./local-dev.md)
  - 本地开发环境初始化与联调步骤
- [release](./release.md)
  - 发布前检查、灰度与回滚要求
- [incident-response](./incident-response.md)
  - 故障定位、止损与复盘流程
- [data-backfill](./data-backfill.md)
  - 数据回补、重建索引与补算说明

## 维护要求
- 运行步骤发生变化时必须同步更新
- 涉及高风险操作时必须补充回滚与审计说明
