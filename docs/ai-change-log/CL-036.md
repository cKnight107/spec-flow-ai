### 1. 目标
完成 `001-model-gateway` 的 P0 基础可用版，形成可通过 HTTP 对外提供统一非流式 chat completion 的模型网关。

### 2. 输入依据

### 3. 本次改动
- 新增统一 DTO、错误码、HTTP controller、application 主链路、路由解析和 provider registry
- 新增 `integrations/model-providers/openai` 与 `integrations/model-providers/anthropic`
- 扩展 `packages/shared-config` 的 model-gateway schema，支持 `providers / models / routes` JSON 注册表
- 新增本地 TypeScript ESM loader，使 `model-gateway` 可直接运行与测试源码
- 同步更新 `001-model-gateway` 规格、任务、API 契约、测试样例与实施路径状态

### 5. 关键决策
- 保持现有零框架依赖基线，P0 先用原生 `node:http + fetch` 跑通统一入口，而不强行引入 NestJS
- provider 差异严格下沉到 `integrations/model-providers/*`，服务层只保留协议、路由与治理编排
- 共享配置首版用 JSON 注册表承载动态模型结构，避免把模型清单写死在代码里
- 新增本地 TS loader，而不是为了测试和运行引入额外第三方运行时依赖
