# AI Change Log

## [CL-022] 将共享配置改造成 YAML + Profile 模式
- 日期：2026-03-14
- 任务编号：TASK-022
- Spec：`docs/specs/012-shared-config/spec.md`
- 执行方式：Codex
- 执行人：AI + Human
- 状态：Done

### 1. 目标
将共享配置从“.env 多文件主配置”改造成“单 `config.yaml` + profile + 分支推断 + `${ENV_VAR}` 插值”模式。

### 2. 输入依据
- 用户要求：统一使用 YAML，允许单文件配置，并支持通过变量引用 `.env`
- 现有实现：`packages/shared-config`
- 额外约束：保持 `server / public / nest` 入口尽量稳定

### 3. 本次改动
- 为 `packages/shared-config` 增加 `yaml` 依赖
- 重写 `server/load-config.ts`，支持 `config.yaml`、`profiles`、`branchProfiles`、`${ENV_VAR}` 插值和分支推断
- 为 `public` 增加 `loadPublicConfig`，让前端也可读取同一份 YAML
- 调整 `admin-console` 公共配置接入，改为从 YAML 加载
- 重写 `shared-config` 单测，覆盖 YAML/profile/branch/interpolation/public 新行为
- 更新 `packages/shared-config/README.md`

### 4. 涉及文件
- `packages/shared-config/package.json`
- `packages/shared-config/src/core/*`
- `packages/shared-config/src/server/*`
- `packages/shared-config/src/public/*`
- `packages/shared-config/README.md`
- `apps/admin-console/lib/public-config.ts`
- `docs/specs/012-shared-config/README.md`
- `docs/ai-change-log/CL-022.md`

### 5. 关键决策
- 保留 `.env`，但角色改为“变量注入源”，而不是主配置载体
- 仍保留 `APP_ENV`，但由显式值、标准 profile 或默认值推断
- profile 优先由显式传参和 `CONFIG_PROFILE` 决定，Git 分支只作为默认推断
- 前端默认改用 `loadPublicConfig`，避免 YAML 和 `process.env` 维护两套配置
