# AI Change Log

## [CL-015] 为 Admin Console 侧边栏增加可伸缩能力
- 日期：2026-03-13
- 任务编号：TASK-015
- Spec：`docs/specs/011-admin-console/spec.md`
- 执行方式：Codex
- 执行人：AI + Human
- 状态：Done

### 1. 目标
将控制台侧边栏改为可伸缩结构，并进一步缩小默认宽度，降低导航对主内容区的挤压。

### 2. 输入依据
- PRD / Spec：`docs/specs/011-admin-console/prd/prd.md`、`docs/specs/011-admin-console/spec.md`
- 用户反馈：侧边栏调整为可伸缩和缩小

### 3. 本次改动
- 修改 `apps/admin-console/lib/consoleLayout.tsx`，新增侧边栏展开/收起状态、切换按钮与本地持久化
- 修改 `apps/admin-console/app/globals.css`，增加收起态宽度、收起态导航/环境卡/角色区样式以及更窄的默认侧边栏
- 收起态下导航改为两字缩写，保持窄栏可读性

### 4. 涉及文件
- `apps/admin-console/lib/consoleLayout.tsx`
- `apps/admin-console/app/globals.css`

### 5. 关键决策
- 侧边栏状态通过 `localStorage` 保留，避免用户每次刷新都重新展开
- 收起态不保留完整文案，直接切到更短的导航缩写，避免窄栏只是在“硬挤”

### 7. 风险与未完成项

### 9. 结果摘要
`apps/admin-console` 已支持侧边栏展开/收起，并进一步缩小默认导航宽度，主内容区可用空间增加。
