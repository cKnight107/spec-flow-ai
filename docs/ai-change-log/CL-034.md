## [CL-034] 为 shared-config 增加 prefix 绑定能力
- 日期：2026-03-26
- 任务编号：TASK-SHARED-CONFIG-PREFIX-BINDING
- Spec：
  - `docs/specs/017-shared-config-prefix-binding/spec.md`
- 执行方式：Codex
- 执行人：AI + Human
- 状态：Done

### 1. 目标
让 `packages/shared-config` 支持类似 Spring Boot `@ConfigurationProperties(prefix = "...")` 的接入方式，使接入方可通过嵌套 YAML 与 camelCase 字段定义按前缀读取一组配置。

### 2. 输入依据
- PRD / Spec：
  - `docs/specs/012-shared-config/spec.md`
  - `docs/specs/017-shared-config-prefix-binding/spec.md`
- ADR / 设计文档：
  - `docs/rules/architecture-boundaries.md`
  - `docs/rules/ts.md`
  - `docs/rules/testing-quality.md`

### 3. 本次改动
- 新增：
  - `defineConfigProperties()` helper
  - 字段级 `sourceKey` / `yamlPath` 绑定元信息
  - 嵌套 YAML 拍平解析能力
  - prefix 绑定单测与对应 spec/tasks
- 修改：
  - `packages/shared-config` 的 schema 解析流程，支持从 YAML 路径与环境变量双通道取值
  - `README.md`，增加 prefix 绑定示例
- 删除：
  - 无

### 4. 涉及文件

- `docs/ai-change-log/CL-034.md`

### 5. 关键决策
- 不重构现有平面 schema 输出模型，只新增 prefix helper 与路径绑定能力，避免影响已有接入方。
- 仍保持环境变量覆盖 YAML 的能力，以兼容部署环境通过注入方式下发敏感值。
- 当前仅支持嵌套对象与标量数组；对象数组与树状输出留待后续独立需求处理。

### 7. 风险与未完成项
- 当前“类似 Spring Boot”仅覆盖 prefix 路径绑定，不等同于完整的树状 `@ConfigurationProperties` 对象模型。
- 数组仍沿用标量数组策略，不支持对象数组直接绑定。

### 8. 人工介入记录
- 是否人工修改：否
- 人工确认点：
  - 是否需要继续支持树状输出，而不仅是前缀绑定后的扁平结果对象
  - 是否需要增加 `number[]`、`boolean[]` 或对象数组 parser

### 9. 结果摘要
`shared-config` 已支持通过 prefix 定义一组 camelCase 字段，并从嵌套 YAML 路径或同名环境变量中读取值，能够满足 `wechat.*` 这类 Spring Boot 风格配置场景。
