### 1. 目标
在现有控制台页面结构基础上，落地一套现代化、简洁化的浅色/深色双主题视觉系统，并收敛导航、顶栏和首页的整体设计语言。

### 2. 输入依据
- PRD / Spec：`docs/specs/011-admin-console/prd/prd.md`、`docs/specs/011-admin-console/spec.md`
- 规则约束：`docs/rules/style.md`
- 设计输入：用户要求“现代化风格 + 简洁风格，需要浅色模式和深色模式”

### 3. 本次改动
- 重写 `apps/admin-console/app/globals.css`，建立浅色/深色主题 token、背景材质、卡片层级、动效与响应式规则
- 修改 `apps/admin-console/app/layout.tsx`，在首屏注入主题初始化脚本，避免深色模式闪回
- 修改 `apps/admin-console/lib/consoleLayout.tsx`，新增主题切换控件并调整顶栏结构
- 修改 `apps/admin-console/lib/navigation.ts`，收敛主导航条目，使其更接近正式控制台
- 修改仪表盘文案与区块语义，使首页更偏治理控制台而非工程占位页

### 4. 涉及文件
- `apps/admin-console/app/globals.css`
- `apps/admin-console/app/layout.tsx`
- `apps/admin-console/lib/consoleLayout.tsx`
- `apps/admin-console/lib/navigation.ts`
- `apps/admin-console/app/(console)/dashboard/page.tsx`

### 5. 关键决策
- 视觉方向采用 `refined minimal + industrial control plane`，避免再次回到泛化 AI 仪表盘样式
- 双主题不依赖第三方库，直接通过 `documentElement.dataset.theme` 与 `localStorage` 管理，保持实现轻量
- 通过顶部主题切换和首屏初始化脚本兼顾可用性与首次加载体验
- 继续保留现有页面信息架构，优先通过主题、材质和层级提升整体质感
