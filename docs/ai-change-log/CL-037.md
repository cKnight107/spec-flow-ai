# AI Change Log

## [CL-037] 将模型 provider adapter 切换为官方 SDK
- 日期：2026-03-27
- 任务编号：TASK-037
- Spec：`docs/specs/001-model-gateway/spec.md`
- 执行方式：Codex
- 执行人：AI + Human
- 状态：Done

### 1. 目标
按新的实现约束，将 `model-gateway` 的 provider adapter 从原生 `fetch` 优先切换为供应商官方 SDK。

### 2. 输入依据
- PRD / Spec：`docs/specs/001-model-gateway/spec.md`
- ADR / 设计文档：`docs/rules/architecture-boundaries.md`
- 额外约束：用户要求“优先使用具体供应商 SDK”

### 3. 本次改动
- 为 OpenAI adapter 引入 `openai`
- 为 Anthropic adapter 引入 `@anthropic-ai/sdk`
- 将两个 adapter 的实际调用逻辑切换为官方 SDK 客户端
- 保留统一的 usage / finishReason / 错误映射结构

### 4. 涉及文件
- `integrations/model-providers/openai/package.json`
- `integrations/model-providers/openai/src/index.ts`
- `integrations/model-providers/anthropic/package.json`
- `integrations/model-providers/anthropic/src/index.ts`
- `pnpm-lock.yaml`
- `docs/ai-change-log/CL-037.md`

### 5. 关键决策
- 继续由 gateway 维护统一 DTO 和错误码，只将上游调用层切换为 SDK
- SDK 客户端统一显式传入 `baseURL / timeout / defaultHeaders / maxRetries`
- 先覆盖当前已接入的 OpenAI 与 Anthropic；`azure-openai` 兼容入口暂不扩展
