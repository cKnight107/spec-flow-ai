# AI Change Log

## [CL-016] 为 Admin Console 侧边栏增加拖拽调宽能力
- 日期：2026-03-13
- 任务编号：TASK-016
- Spec：`docs/specs/011-admin-console/spec.md`
- 执行方式：Codex
- 执行人：AI + Human
- 状态：Done

### 1. 目标
在现有可收起侧边栏基础上，增加可拖拽调宽能力，让用户可以按自己的阅读习惯控制导航占用空间。

### 2. 输入依据
- PRD / Spec：`docs/specs/011-admin-console/prd/prd.md`、`docs/specs/011-admin-console/spec.md`
- 用户反馈：侧边栏做成可拖拽

### 3. 本次改动
- 修改 `apps/admin-console/lib/consoleLayout.tsx`，新增侧边栏宽度状态、拖拽逻辑与本地持久化
- 修改 `apps/admin-console/app/globals.css`，为侧边栏增加拖拽把手、拖拽态样式和基于 CSS 变量的动态宽度
- 保持收起态逻辑不变，拖拽仅在展开态生效

### 4. 涉及文件
- `apps/admin-console/lib/consoleLayout.tsx`
- `apps/admin-console/app/globals.css`

### 5. 关键决策
- 拖拽使用原生 pointer 事件实现，避免引入额外依赖
- 宽度限制在最小/最大值区间内，防止侧边栏过窄或过宽破坏布局
- 宽度写入 `localStorage`，刷新后保留用户上次调整结果
