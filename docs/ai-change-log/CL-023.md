## [CL-023] 将共享配置切换为分文件 YAML 模式
- 日期：2026-03-14
- 任务编号：TASK-023

- 执行方式：Codex

### 1. 目标
将共享配置从“单 `config.yaml` + profiles”调整为“`config.yaml` 基线 + `config-<profile>.yaml` 覆盖”的分文件模式。

### 2. 输入依据
- 用户反馈：分文件环境配置优于单文件 profiles
- 现有实现：`packages/shared-config`
- 额外约束：保留 `${ENV_VAR}` 插值和现有 `server/public/nest` 接口

### 3. 本次改动
- 重写 `packages/shared-config/src/server/load-config.ts`，支持基础配置文件与 profile 配置文件叠加
- 调整配置文件发现策略，支持 `config.yaml|config.yml` 与 `config-<profile>.yaml|config-<profile>.yml`
- 重写 `shared-config` 单测，覆盖分文件叠加、分支选择 profile、public 加载与诊断输出
- 更新 `packages/shared-config/README.md`
- 更新 `docs/specs/012-shared-config/README.md`

### 4. 涉及文件
- `packages/shared-config/src/core/env.ts`
- `packages/shared-config/src/server/load-config.ts`
- `packages/shared-config/src/server/shared-config.test.ts`
- `packages/shared-config/README.md`
- `docs/specs/012-shared-config/README.md`
- `docs/ai-change-log/CL-023.md`

### 5. 关键决策
- 保留 `config.yaml` 作为共享默认值，避免每个 profile 文件重复公共字段
- profile 文件采用 `config-<profile>.yaml` 命名，便于扫描和审查
- Git 分支只用于推断 profile 名，不再使用 `branchProfiles` 配置映射
- `.env` / `.env.local` 继续只承担变量注入职责
