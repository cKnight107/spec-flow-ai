### 5. 关键决策
- 避免在当前阶段引入外部运行时依赖阻塞开发，先实现一套纯 TypeScript 的最小共享 SDK，后续再接 OpenTelemetry exporter 或 Pino 实例

- `model-gateway` 先以包装器形式落地，而不是提前绑定具体 HTTP controller 或 provider SDK，便于后续复用到不同入口层
