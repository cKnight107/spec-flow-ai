# 产品需求文档（PRD）

## 目标
建设统一的企业 AI 中台，沉淀模型、知识、工具、智能体、权限、审计与观测等公共能力，支持多业务线快速交付 AI 应用。

## 核心价值
- 统一模型接入、路由、配额和成本治理
- 统一知识接入、索引、检索、溯源和权限继承
- 统一工具接入、调用权限和 Agent / Workflow 编排
- 统一应用装配、发布、审计和运营观测

## 本期能力域
1. 模型网关与路由中心
2. 知识与记忆中心
3. 智能体与工作流中心
4. 工具与协议中心
5. PromptOps / EvalOps 中心
6. 应用交付中心
7. 身份权限与治理中心
8. 观测运营与成本中心

## 核心角色
- 平台管理员
- 应用管理员
- 知识管理员
- 开发者 / 集成人员
- 普通业务用户
- 安全 / 审计人员

## 交付原则
- 复用优先
- 平台优先
- 数据优先
- 安全前置
- 分阶段建设
- 配置优先
