# 011 Admin Console 第一阶段 PRD

## 1. 文档目标
本 PRD 用于驱动企业 AI 中台后台管理系统的高保真 UI 原型设计与静态前端开发。第一阶段只定义信息架构、页面布局、用户路径、关键交互、状态流转、组件骨架与权限占位，不包含后端接口、真实鉴权、联调协议与持久化行为。

## 2. 适用角色
- 平台管理员：维护模型、路由、配额、安全策略、全局观测与审计。
- 应用管理员：创建和配置应用，绑定模型、知识、工具与工作流。
- 知识管理员：维护知识库、文档导入任务、权限映射与更新策略。
- 开发者：管理工具、Prompt、Playground、发布配置和调试信息。
- 审计人员：查看审批、操作记录、执行轨迹和成本异常。

## 3. 阶段边界
### 3.1 本阶段包含
- 一级导航、二级菜单、路由树和页面命名
- 控制台统一壳层、导航、面包屑、上下文切换区
- 列表页、详情页、配置页、审计页、观测页的布局定义
- 页面级用户任务路径、关键动作、反馈方式与空态/异常态
- 权限占位、审批占位、静态数据和组件骨架规范

### 3.2 本阶段不包含
- 接入真实后端、数据库、鉴权中心和审批流引擎
- 编写 API Schema、Mock Server、SSE 或轮询协议
- 工作流拖拽编排器、链路追踪图等复杂交互的实现细节
- 完整设计系统 Token、组件库工程化和代码实现

## 4. 设计原则
- 配置优先：页面以“查看配置、变更配置、发布配置、审计配置”为核心路径。
- 治理前置：所有高风险操作预留权限、审批、风险提示和审计入口。
- 信息分层：列表页优先摘要，详情页承接配置分组，复杂信息放入抽屉、标签页或侧栏。
- 静态可演示：所有页面允许用固定 JSON 驱动，确保原型阶段能完整演示主路径。
- 状态明确：每个页面至少覆盖加载中、空态、成功态、失败态、无权限态。

### 5.3 菜单显示规则
- 一级菜单固定显示，二级菜单根据当前一级菜单展开。
- 用户无权限时菜单仍可显示，但入口呈禁用态并附带“需申请权限”文案。
- 审计人员默认隐藏配置类“新建”和“编辑”按钮，但保留只读入口。
- 高风险域统一显示风险标记，包括模型路由、知识权限映射、工具鉴权、发布和策略变更。

## 6. 全局布局定义
### 6.1 框架布局
- 左侧：主导航栏，包含产品标识、一级菜单、环境标记和折叠开关。
- 顶部：组织/空间切换、全局搜索、快捷创建、审批提醒、用户菜单。
- 主内容区：面包屑、页面标题、操作按钮区、页面内容区。
- 右侧扩展区：仅在详情页和审计页出现，用于展示摘要卡片、操作历史或帮助说明。

### 6.2 全局交互
- 列表页支持搜索、筛选、排序、分页和批量操作占位。
- 详情页默认使用 `概览 + 配置分组标签页 + 右侧摘要` 三栏思路。
- 所有提交类动作统一使用顶部按钮区，删除/发布/下线等高风险动作固定二次确认。
- 支持从全局搜索跳转到应用、模型、知识库、工具、工作流详情页。

### 6.3 全局状态
- `loading`：展示骨架屏，不出现空白页面。
- `empty`：展示说明、引导 CTA 和示例数据占位。
- `error`：展示错误摘要、重试按钮和关联帮助链接占位。
- `forbidden`：展示无权限说明、申请权限入口和可联系角色说明。
- `approval-pending`：展示审批横幅，标明待审批动作、发起人和影响范围。

## 7. 页面级 PRD
### 7.1 仪表盘 `/admin/dashboard`
#### 页面目标
让平台管理员快速看到系统健康度、应用运行概览、待处理审批与风险事件。

#### 页面布局
- 顶部指标卡：应用数、模型调用量、知识导入任务、审批待办、异常告警。
- 中部左侧：近期请求趋势、成本趋势。
- 中部右侧：待审批事项、风险事件、失败任务。
- 底部：常用快捷入口和最近访问资源。

#### 用户路径
1. 查看今日运行概况。
2. 点击异常卡片进入相应治理页面。
3. 从快捷入口进入应用、模型或知识详情。

#### 关键交互
- 时间范围切换仅改变静态图表数据，不触发真实查询。
- 异常卡片点击后跳转对应列表并保留筛选条件展示。

### 7.2 应用列表 `/admin/apps`
#### 页面目标
查看应用资产、快速筛选状态、进入创建和维护流程。

#### 页面布局
- 页头：页面标题、说明、`新建应用` 按钮。
- 筛选区：关键词、负责人、类型、状态、发布渠道。
- 表格区：应用名称、归属部门、绑定模型、绑定知识库、状态、最近发布时间、负责人。
- 右侧抽屉：点击行后展示应用摘要、版本、反馈和快捷操作。

#### 用户路径
1. 按部门或状态筛选应用。
2. 点击应用名称进入详情页。
3. 点击 `新建应用` 进入表单流程。

#### 关键交互与状态
- 无数据时提供“按模板创建应用”入口。
- 草稿、已发布、已下线三种状态用状态徽标区分。
- 对已发布应用点击“下线”时显示审批占位横幅。

### 7.3 应用详情 `/admin/apps/:appId/*`
#### 页面目标
围绕单个应用完成配置、绑定、发布和反馈分析。

#### 子页布局
- `overview`：应用摘要、当前版本、绑定资源、近 7 天调用趋势。
- `config`：基本信息、接入渠道、会话策略、安全开关。
- `bindings`：模型、知识库、工具、工作流绑定关系，可视化关系卡片。
- `release`：版本列表、发布记录、环境标记、回滚入口占位。
- `feedback`：评分分布、问题分类、典型差评样本。

#### 用户路径
1. 从列表进入概览。
2. 切换到 `bindings` 查看依赖资源。
3. 在 `release` 页面执行发布或回滚占位动作。

#### 关键交互
- 配置变更后统一显示“未发布变更”提示条。
- 发布前弹出影响范围确认框，需显示目标渠道、版本号和审批要求。
- 回滚入口默认禁用，仅平台管理员可见。

### 7.4 模型中心 `/admin/models` 与详情
#### 页面目标
管理模型资产、路由策略、配额和安全控制。

#### 页面布局
- 列表页：模型名称、供应商、类型、状态、默认路由权重、限流、更新时间。
- 详情页概览：基础信息、支持能力、调用趋势、失败率。
- `routing`：路由规则、主备模型、灰度比例、降级策略卡片。
- `quota`：应用级、部门级配额表格。
- `safety`：敏感场景限制、脱敏策略、审核开关。

#### 关键交互
- 路由策略修改时展示“影响应用数”和风险提示。
- 降级策略、灰度比例使用静态表单与预估影响卡片表示。

### 7.5 知识中心 `/admin/knowledge` 与详情
#### 页面目标
维护知识库、文档导入任务、权限映射和检索配置。

#### 页面布局
- 列表页：知识库名称、数据源类型、文档数、状态、更新时间、负责人。
- `documents`：文档表格、导入状态、解析结果、失败原因。
- `pipelines`：导入任务时间线、分阶段状态、重试入口。
- `permissions`：组织权限映射、文档继承规则、受限标记。
- `retrieval`：召回策略、重排开关、引用阈值。

#### 关键交互
- 文档导入失败展示失败原因抽屉和“重试导入”按钮。
- 权限映射页必须展示只读说明，标明“未接 IAM，仅为原型占位”。

### 7.6 工具中心 `/admin/tools` 与详情
#### 页面目标
管理工具定义、输入输出 Schema、鉴权方式和执行记录。

#### 页面布局
- 列表页：工具名称、协议类型、提供方、发布状态、风险等级、最近调用时间。
- `schema`：入参/出参 JSON Viewer、示例请求响应。
- `authorization`：鉴权方式、密钥来源、权限范围、审批要求。
- `executions`：调用结果表格、耗时、状态、错误信息、链路跳转占位。

#### 关键交互
- 高风险工具显示审批横幅和风险说明。
- JSON 区域默认只读，支持切换示例版本。

### 7.7 工作流 `/admin/workflows` 与详情
#### 页面目标
展示工作流资产、版本、执行和审批节点，不实现编排器。

#### 页面布局
- 列表页：工作流名称、业务域、版本、状态、最近运行、负责人。
- `overview`：流程摘要、节点统计、输入输出示意图。
- `versions`：版本表格、变更摘要、发布记录。
- `runs`：执行列表、状态、耗时、失败节点、重试入口。
- `approvals`：审批节点表、触发条件、当前状态。

#### 关键交互
- `overview` 中只展示流程静态示意图，不做拖拽编辑。
- 执行失败行支持打开时间线抽屉查看节点级状态。

### 7.8 PromptOps `/admin/promptops/*`
#### 页面目标
为开发者提供 Prompt 列表、版本对比、Playground 和评测结果入口。

#### 页面布局
- `prompts`：Prompt 列表、标签、适用应用、版本、最近发布时间。
- `prompts/:promptId`：Prompt 基本信息、版本差异、关联资源。
- `playground`：左侧输入区，中间参数区，右侧结果区与引用/工具执行占位。
- `evaluations`：评测集列表、评分分布、失败样本摘要。

#### 关键交互
- Playground 不接模型，只使用静态问答结果、引用面板和工具时间线示例。
- Prompt 版本切换后刷新右侧差异摘要。

### 7.9 审计与审批 `/admin/governance/*`
#### 页面目标
承接审计查询、审批处理和风险事件查看。

#### 页面布局
- `audit-logs`：按资源类型、操作人、时间、结果过滤的日志表格。
- `approvals`：审批卡片列表、状态、发起人、影响范围、处理动作。
- `risk-events`：风险类型、资源、检测时间、当前状态、处置建议。

#### 关键交互
- 审批操作采用详情抽屉，展示变更前后对比和审批意见输入框占位。
- 审计日志支持跳转资源详情和链路详情页。

### 7.10 观测与成本 `/admin/observability/*`
#### 页面目标
让管理员查看请求趋势、执行链路、错误分布和成本排行。

#### 页面布局
- `overview`：请求量、成功率、平均时延、引用率、工具调用成功率。
- `requests`：请求列表、过滤条件、状态、链路 ID、入口应用。
- `traces`：链路时间线、模型调用、检索、工具执行、审批挂起占位。
- `costs`：按部门、应用、模型、用户维度的成本排行与趋势。

#### 关键交互
- 链路详情页用时间线组件替代真实调用图。
- 成本排行卡支持维度切换，并在高成本项旁展示异常提示。

### 7.11 权限治理 `/admin/access/*`
#### 页面目标
提供用户、角色、策略的只读/半配置原型页面。

#### 页面布局
- `users`：用户表格、部门、状态、角色、最近登录。
- `roles`：角色列表、权限摘要、关联人数。
- `policies`：策略列表、资源范围、动作范围、生效条件。

#### 关键交互
- 所有权限编辑动作均为占位状态，弹窗内提示“待接企业 IAM/策略引擎”。
- 角色详情中展示与应用、知识库、工具的资源授权示意。

## 8. 统一组件骨架
### 8.1 页面级通用组件
- `PageHeader`：页面标题、描述、主操作、次操作、面包屑。
- `SearchFilterBar`：搜索、筛选、标签、排序、时间范围。
- `DataTable`：列配置、状态徽标、批量选择、行操作、分页。
- `StatusBadge`：草稿、运行中、成功、失败、已下线、审批中、无权限。
- `EmptyState`：说明、示例图、CTA。
- `SectionCard`：页面分组卡片，包含标题、说明、右上操作。

### 8.2 详情与治理组件
- `JsonViewer`：只读 JSON 展示、代码块切换、复制入口占位。
- `ApprovalBanner`：高风险变更提醒、审批状态、发起人、预计影响范围。
- `ToolExecutionTimeline`：节点名称、开始时间、耗时、状态、错误摘要。
- `DiffPreview`：变更前后对比卡，用于发布和审批页。
- `MetricCard`：数字、趋势、风险标记、说明文字。
- `SideSummaryPanel`：资源摘要、负责人、标签、最近操作。

### 8.3 骨架屏规则
- 列表页展示 5 到 8 行表格骨架。
- 详情页展示标题骨架、3 个摘要卡、2 个区块卡骨架。
- 时间线类页面展示 6 条节点骨架。

## 9. 权限占位规则
- 页面可见性分为 `可访问`、`只读`、`不可访问` 三档。
- `只读` 页面允许查看列表、详情和日志，不显示保存、删除、发布按钮。
- `不可访问` 页面允许进入占位页，展示申请权限流程说明，保持导航结构稳定。
- 高风险操作统一增加 `审批中` 状态，不因为未接审批流而省略入口。
- 资源级权限通过标签形式占位展示，例如“部门可见”“仅平台管理员可操作”。

## 10. 静态数据与原型约束
- 所有图表、表格、时间线、JSON 示例均来自本地静态数据文件。
- 页面主路径至少准备 1 组成功数据、1 组空态数据、1 组异常数据。
- 标题、状态、角色、资源名称使用统一命名，避免设计稿与后续实现脱节。
- 原型阶段不引入真实品牌 Logo、敏感客户数据和生产环境信息。

## 11. 关键状态流转
### 11.1 通用状态
`未配置 -> 草稿 -> 已保存未发布 -> 审批中 -> 已发布 -> 已下线`

### 11.2 导入与执行状态
`排队中 -> 处理中 -> 部分成功 -> 成功`
`排队中 -> 处理中 -> 失败 -> 重试中 -> 成功`

### 11.3 风险与审批状态
`待提交 -> 待审批 -> 审批通过 -> 已执行`
`待提交 -> 待审批 -> 审批拒绝 -> 返回修改`

## 12. 典型用户操作路径
### 12.1 应用管理员创建应用
1. 进入应用列表，点击 `新建应用`。
2. 填写基础信息并保存草稿。
3. 在绑定页关联模型、知识库、工具和工作流。
4. 在发布页查看变更摘要并提交发布。
5. 若命中高风险规则，页面显示审批横幅并进入待审批状态。

### 12.2 平台管理员调整模型路由
1. 从模型列表进入某模型详情。
2. 打开 `routing` 页面查看当前权重和主备关系。
3. 修改灰度比例和降级策略。
4. 查看影响应用数、预计风险说明。
5. 提交后进入审批中或直接保存为草稿。

### 12.3 知识管理员处理导入失败
1. 打开知识库详情的 `pipelines` 页面。
2. 过滤失败任务。
3. 在时间线抽屉查看失败节点和原因。
4. 点击 `重试导入`，任务状态切换为重试中。

### 12.4 审计人员追查异常调用
1. 进入 `audit-logs` 或 `observability/requests`。
2. 按时间、应用、状态筛选异常请求。
3. 打开链路详情查看模型、检索、工具调用时间线。
4. 回跳到相关应用或工具详情页继续定位。

## 13. 页面验收标准
- 一级菜单、二级菜单、路由命名、页面标题和角色入口保持一致。
- 每个一级菜单至少包含 1 个列表页和 1 个详情/分析页定义。
- 关键页面均覆盖 `loading`、`empty`、`error`、`forbidden`、`approval-pending` 五类状态。
- 高风险动作均定义确认方式、审批占位和审计入口。
- 通用组件骨架能够支撑第二阶段高保真 UI 编码，不需要重新定义页面结构。
