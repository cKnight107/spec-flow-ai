# Specs 目录说明

本目录用于按模块沉淀可执行规格，供实现、测试和验收统一使用。

## 约定
- 每个规格目录至少包含 `spec.md` 与 `tasks.md`
- API 边界明确的模块补 `api.yaml`
- 验收前补充 `test-cases.md`
- 关键数据结构可在 `schema.md` 中描述
