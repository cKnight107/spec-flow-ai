# TypeScript 规范

## 类型安全
- 禁止直接使用 `any`，确需使用时必须说明原因，并优先使用 `unknown`、泛型或精确定义的联合类型代替。
- 禁止通过类型断言链掩盖真实类型问题，例如 `as any as Foo`。
- 公共接口、服务返回值、组件 props、hooks 返回值必须显式建模。

## 语法约束
- 优先使用可选链 `?.` 和空值合并 `??`，避免多层 `&&` 和 `||` 带来的语义歧义。
- 优先使用 `const`，只有变量需要重新赋值时才使用 `let`。
- 优先使用 `type` 表达组合类型，涉及可扩展对象契约时再使用 `interface`。
- 异步逻辑统一使用 `async/await`，避免无必要的 `.then()` 链式嵌套。

## 空值与边界处理
- 所有可空字段都要在类型层显式表达，不允许依赖运行时猜测。
- 数组、对象、接口响应在消费前必须做空值和异常态处理。
- 枚举状态优先使用字面量联合类型，避免魔法字符串散落在代码中。

## 共享类型
- 跨模块复用的 DTO、枚举、领域对象统一放在 `packages/shared-types` 或对应 schema 包中。
- 禁止不同服务复制一份相似但不一致的类型定义。
